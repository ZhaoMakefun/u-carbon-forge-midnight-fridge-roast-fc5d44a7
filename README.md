# Midnight Fridge Roast

Midnight, and the fridge has decided it is a bouncer now. Locked tight, lights off for you, but still delivering a lecture about your choices through a door it will not even open. The roast writes itself — an appliance that guards the snacks and judges you at the same time.

## How to run

```sh
python3 main.py
```

That writes the roast (128 characters) to `$MAKEFUN_OUTPUT_DIR/entry.txt`, or `/output/entry.txt` when the variable is unset. Python 3 standard library only, no network, identical output on every run.
